# Railway deployment instructions

1. Go to railway.app
2. Sign in with GitHub
3. Click "New Project"
4. Select "Deploy from GitHub repo"
5. Choose your repository
6. Railway will automatically detect Next.js
7. Add PostgreSQL database (free)
8. Set environment variables:
   - NEXTAUTH_SECRET
   - NEXTAUTH_URL (will be provided after deployment)
   - DATABASE_URL (will be auto-generated)
   - NODE_ENV=production

Railway automatically provides:
- Free PostgreSQL database
- Custom domain
- SSL certificate
- $5/month credit (usually enough for small apps)
