# 🚀 Cohort System - Quick Start Guide

## How to Access Cohorts in UI

### 👨‍🏫 **For CREATORS:**

**1. Navigate to Cohorts:**
```
Login → Creator Dashboard → Look at LEFT SIDEBAR → Click "Cohorts" button
```

**Alternative paths:**
- From `/creator/courses` → Click "Cohorts" in sidebar
- From `/creator/analytics` → Click "Cohorts" in sidebar
- Direct URL: `/en/creator/cohorts` or `/ar/creator/cohorts`

**2. Create Your First Cohort:**
```
1. Click "Create Cohort" button
2. Select a course
3. Set start/end dates
4. Set enrollment deadline
5. Set max members (optional)
6. Add description
7. Click "Create"
```

**3. Manage Cohort:**
```
Click on cohort card → 5 tabs appear:
├── Overview (Edit details, view stats)
├── Members (Approve applications, manage students)
├── Sessions (Schedule live sessions, track attendance)
├── Announcements (Post updates to students)
├── Milestones (Assign deadlines and projects)
└── Analytics (Track progress and engagement)
```

---

### 🎓 **For STUDENTS:**

**1. Browse Available Cohorts:**
```
Direct URL: /en/student/cohorts or /ar/student/cohorts
```

**2. Apply to Join:**
```
1. Browse cohorts
2. Filter by "Open for Enrollment"
3. Click cohort card
4. Click "Apply to Join"
5. Wait for approval
```

**3. View Your Cohorts:**
```
Direct URL: /en/student/dashboard or /ar/student/dashboard
```

## 💡 Best Practices

### For Creators:
1. **Start with DRAFT** - Fine-tune before publishing
2. **Set clear dates** - Give students time to apply
3. **Limit members** - Keep cohorts manageable (10-30)
4. **Post regularly** - Keep students engaged
5. **Track attendance** - Identify at-risk students early
6. **Use milestones** - Create accountability
7. **Review analytics** - Optimize future cohorts

### For Students:
1. **Apply early** - Spots fill up fast
2. **Check deadlines** - Don't miss enrollment windows
3. **Attend sessions** - Participation matters
4. **Complete milestones** - Stay on track
5. **Read announcements** - Stay informed

## 🆘 Troubleshooting

### Can't find Cohorts link?
- Make sure you're logged in as creator
- Check left sidebar on dashboard/courses/analytics pages
- Try direct URL: `/creator/cohorts`

### Can't apply to cohort?
- Check if status is "OPEN"
- Verify enrollment deadline hasn't passed
- Make sure cohort isn't full
- Confirm you haven't already applied

### Not seeing my cohorts?
- Student dashboard: `/student/dashboard`
- Check if application is still pending
- Verify creator approved your application
