## 🚀 Quick Start Guide

### **Step 1: Environment Setup**

```bash
# Terminal 1 - Start development server
npm run dev

# Terminal 2 - Start database viewer
npx prisma studio --port 5556
```

### **Step 2: Prepare Demo Data**

```bash
# Create demo users
npx tsx scripts/create-demo-users.ts

# Create demo conversations and messages
npx tsx scripts/create-demo-messaging-data.ts
```

### **Step 3: Verify System Status**

- ✅ Application running at <http://localhost:3000>
- ✅ Socket.io connection active (green indicator)
- ✅ Demo data loaded successfully
- ✅ All features functional
